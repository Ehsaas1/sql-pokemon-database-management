# sql-pokemon-database-management
A MySQL-based relational database project demonstrating schema design, data integrity constraints, and analytical SQL queries using a structured Pokémon dataset.
## Project Description

This project focuses on designing and implementing a relational database using MySQL to manage structured Pokémon data.  
It demonstrates core SQL concepts including normalized table design, primary and foreign key relationships, data integrity constraints, derived columns, and analytical querying.

The database supports structured analysis through SQL views and optimized queries, making it suitable for reporting and data analysis use cases.
